GBA PLAYER

feito por Gaio Moreira

Um player de Game Boy Advance que roda dentro do navegador: interface própria sobre o emulador mGBA, compilado para WebAssembly. O intuito é praticar WebAssembly, IndexedDB, service workers e controles para toque, sem servidor.

  • HTML
  • CSS
  • JavaScript
  • WebAssembly
  • IndexedDB
  • service worker
