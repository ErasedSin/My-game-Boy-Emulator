GBA Player

feito por Gaio Moreira

Interface própria para o emulador mGBA, compilado para WebAssembly e executado dentro do navegador. O intuito do projeto é praticar a integração de WebAssembly, armazenamento local (IndexedDB), service workers e controles para toque, sem nenhum servidor.

  • HTML, CSS e JavaScript puro
  • núcleo de emulação: mGBA (MPL-2.0), por Vicki Pfau
  • saves persistentes no próprio navegador
